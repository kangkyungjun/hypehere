## 1. 규격 (App Store Connect 요구)

| 규격 | 캔버스 | 대상 기기 | 장수 |
|---|---|---|--:|
| **6.7"** | 1290×2796 | iPhone 14/15/16 Pro Max | 8 |

> 한국이 주 시장이므로 1.10.0부터 포함한다.

## 2. 프레임(기기 목업) 규격

스크린샷은 **다이나믹 아일랜드·카메라까지 있는 실사 목업** 안에 넣는다.
원본 프레임 에셋이 레포에 없으므로, **기존 스크린샷을 템플릿으로 재사용**한다 —
화면 영역만 새 캡처로 덮어쓰면 베젤·배경은 그대로 유지된다.

역산한 규격(기존 파일에서 픽셀 측정):

| 규격 | 화면 영역 좌상단 | 화면 영역 크기 | 종횡비 |
|---|---|---|--:|
| 6.7" | (56, 264) | 1178×2293 | 0.5137 |
| 6.5" | (54, 254) | 1134×2204 | 0.5145 |

원본 캡처(1290×2796)에서 **상태바 186px + 홈인디케이터 102px**를 잘라내면
1290×2508 → 비 0.5144로 화면 영역과 맞는다. 기존 워크플로가 그랬다는 뜻이다.

## 4. 재생성 순서

### ① 캡처 (실제 앱을 조작해 찍는다)
```bash
xcrun simctl boot <6.7" UDID>          # iPhone 16 Pro Max 등
flutter drive \
  --driver=test_driver/screenshot_driver.dart \
  --target=integration_test/screenshot_test.dart \
  -d <6.7" UDID>
```
→ `fastlane/screenshots/_raw/01_home.png` … `08_ticker_chart.png` (프레임 없음)

목데이터가 아니라 **실서버 데이터**로 찍히므로 심사 제출 가능한 화면이 나온다.
캡처 대상 화면과 스크롤 위치는 `integration_test/screenshot_test.dart`에 있다.

### ② 프레임 씌우기 + 로케일 배포
```bash
python3 tool/frame_screenshots.py \
  --locales ko,en-US,en-GB,en-AU,en-CA,es-ES,es-MX,ja,zh-Hans,zh-Hant
```
6.7"/6.5" 두 규격을 만들어 10개 로케일에 복사한다.

> 로케일별로 **다른 언어 화면을 찍고 싶다면** ①을 로케일 수만큼 반복하고
> `--locales`를 하나씩 지정한다. 현재는 한 벌을 전 로케일에 복사한다 —
> 스크린샷 속 문구가 영어여도 심사에 문제되지 않고, 유지 비용이 1/10이다.

### ③ 업로드
```bash
bundle exec fastlane deliver --skip_binary_upload
```
`fastlane/Deliverfile`이 `overwrite_screenshots(true)`라 기존 것을 덮어쓴다.
