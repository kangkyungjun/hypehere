# MarketLens 디자인 재개발 문서

> 최종 업데이트: 2026-05-25  
> 상태: 전면 재정비 진행 예정  
> 목적: Flutter 기본 느낌과 구식 UI를 제거하고, 금융 앱답게 조밀하고 선명한 현대적 인터페이스로 재설계한다.

---

## 1. 현재 판단

현재 앱은 기능은 많지만 화면 인상이 아직 충분히 현대적이지 않다. 특히 다음 문제가 반복된다.

- 좌우 여백이 넓어 콘텐츠가 좁고 허술해 보인다.
- 위아래 간격이 과해 한 화면에 들어오는 정보량이 부족하다.
- 카드, 선, 배경, 칩, 탭, 차트의 시각 강도가 서로 맞지 않는다.
- Flutter 기본 위젯 느낌이 남아 있어 제품 완성도가 낮아 보인다.
- 일부 구분선과 카드 테두리가 화면을 더 복잡하게 만든다.
- 차트는 실제 그래프 영역보다 여백이 커서 전문 금융 앱처럼 보이지 않는다.
- 색상은 많이 쓰면 안 되며, 흰색/검정 기반에 필요한 곳만 포인트 컬러를 쓴다.

핵심 방향은 "예쁘게 꾸미기"가 아니라 정보 밀도, 대비, 정렬, 일관성을 먼저 바로잡는 것이다.

## 2. 디자인 원칙

### 2-1. 색상

- 기본 배경은 라이트 모드 `white`, 다크 모드 `black`에 가깝게 유지한다.
- 은은한 파란 배경을 넓은 면적에 깔지 않는다.
- 포인트 컬러는 상승/하락, 선택 상태, 핵심 액션에만 제한적으로 사용한다.
- 선택된 탭/칩은 색 면적보다 텍스트 대비, 얇은 보더, 미세한 배경 차이로 표현한다.
- 카드 배경과 페이지 배경 차이가 과하면 촌스러워 보이므로 과한 박스 느낌을 피한다.

### 2-2. 간격

- 모바일 금융 앱은 넓은 여백보다 정보 밀도가 중요하다.
- 화면 좌우 기본 여백은 `16px`을 기준으로 한다.
- 리스트형 화면은 필요 시 `12~16px`까지 줄인다.
- 카드 내부 패딩은 기본 `16px`, 복잡한 차트/리스트는 `12~16px`로 조절한다.
- 섹션 간격은 기본 `16~20px`, 특별한 대형 분리만 `24px`까지 허용한다.
- `32px` 이상 간격은 거의 사용하지 않는다.

### 2-3. 카드와 구분

- 카드는 모든 영역을 감싸는 장식물이 아니라 정보 묶음이 필요할 때만 사용한다.
- 카드 테두리는 `0.6~0.8px` 수준으로 약하게 유지한다.
- 그림자는 기본적으로 쓰지 않거나 아주 약하게 쓴다.
- 이미 카드로 감싼 영역 뒤에 또 다른 탭바/바닥 영역을 만들지 않는다.
- 구분선은 두껍게 쓰지 않는다. 일반 구분선은 `1px` 이하가 기본이다.

### 2-4. 타이포그래피

- 본문과 보조 텍스트의 대비가 너무 낮으면 가시성이 떨어진다.
- 핵심 숫자, 종목명, 등락률, 스코어는 명확한 굵기와 색 대비를 가져야 한다.
- 작은 글씨를 남발하지 않는다. 작게 쓰더라도 대비를 확보한다.
- 제목은 크게만 만드는 것이 아니라 주변 간격과 함께 계층을 만든다.

### 2-5. 차트

- 차트는 MarketLens의 신뢰감을 좌우하는 핵심 영역이다.
- 차트 내부 패딩을 과하게 두지 않는다.
- 실제 그래프 영역을 최대화한다.
- 주요 선은 너무 얇거나 흐리면 안 된다.
- 그리드 라인은 보조 역할만 해야 하며 그래프보다 눈에 띄면 안 된다.
- 축 라벨은 작더라도 읽을 수 있어야 한다.
- 여러 지표를 동시에 보여줄 때는 색상 수를 제한하고 우선순위를 분명히 한다.

### 2-6. 모달

- 모달은 화면과 같은 디자인 언어를 따라야 한다.
- 둥근 모서리, 핸들바, 내부 여백, 버튼 위치를 통일한다.
- 모달 내부 카드 중첩은 피한다.
- 필터 모달은 선택 상태가 명확해야 하며 불필요한 설명 문구를 줄인다.

## 3. 현재 적용된 1차 정리

2026-05-25 기준으로 다음 정리를 적용했다.

- 전역 간격 토큰 축소
  - `xl: 20 -> 16`
  - `xxl: 24 -> 20`
  - `xxxl: 32 -> 24`
- `BentoCard` 기본 패딩 `20 -> 16`
- 하단 탭바 높이와 외곽 여백 축소
- 대시보드, 뉴스, AI Lens 주요 화면 외곽 여백 축소
- 뉴스 리스트 아이템 세로 간격 축소
- 티커 상세 차트 내부 패딩 축소
- 차트 주요 선 두께와 대비 소폭 강화
- 티커 상세의 두꺼운 구분선 제거

이 작업은 최종 디자인이 아니라 전면 재설계를 위한 밀도 보정 1차 작업이다.

## 4. 재개발 우선순위

### Phase 1. 디자인 시스템 재정비

- `app_colors.dart`: 배경, 카드, 텍스트, 보더, 차트 색상 재정의
- `app_spacing.dart`: 화면/카드/리스트/차트 기준 간격 확정
- `app_radius.dart`: 카드, 칩, 모달, 탭바 반경 기준 확정
- `app_typography.dart`: 금융 앱용 숫자/라벨/제목 계층 정리
- `app_shadow.dart`: 그림자 사용 최소화

완료 기준:

- 새 화면을 만들 때 별도 색상/간격 값을 임의로 만들 필요가 없어야 한다.
- `Color(0x...)`, 임의 `EdgeInsets`, 임의 `TextStyle` 사용을 계속 줄인다.

### Phase 2. 핵심 화면 재설계

우선순위는 사용자 체감이 큰 화면부터 진행한다.

1. Dashboard
2. Ticker Detail
3. News
4. AI Lens
5. Watchlist
6. Holdings
7. Community
8. Settings/Auth/Profile

완료 기준:

- 각 화면의 첫 화면에서 정보가 충분히 보인다.
- 좌우/상하 여백이 과하지 않다.
- 카드가 과도하게 중첩되지 않는다.
- 탭/필터/칩 상태가 명확하다.

### Phase 3. 차트/그래프 전면 개선

대상:

- 가격 차트
- AI Score 차트
- Volume 차트
- Macro history chart
- Earnings chart
- Treemap
- Compare chart

작업 기준:

- 그래프 실제 면적 확대
- 선 두께/색/그리드/축 라벨 재정의
- 불필요한 범례/박스/여백 제거
- 상승/하락/중립 표현 일관화
- 다크모드 가독성 별도 검증

### Phase 4. 모달/필터/상태 화면 통일

대상:

- 뉴스 필터 모달
- Market news modal
- Gold upgrade sheet
- 로그인/회원가입 모달성 화면
- 알림 권한/설정 유도 화면
- 빈 상태, 에러 상태, 로딩 상태

완료 기준:

- 모든 모달의 상단, 하단 버튼, 내부 여백이 일관적이어야 한다.
- 필터 적용 상태는 중복 표시하지 않는다.
- 빈 상태와 에러 상태가 Flutter 기본 화면처럼 보이지 않아야 한다.

### Phase 5. 전체 QA와 디테일 보정

- 라이트/다크 모드 화면별 점검
- 작은 기기와 큰 기기에서 여백 확인
- 긴 한국어/영어 텍스트 줄바꿈 확인
- 터치 영역 44~48dp 확보
- `flutter analyze` 유지
- 필요 시 스크린샷 기반으로 화면별 디자인 리뷰 기록

## 6. 작업 방식

앞으로 디자인 작업은 다음 순서로 진행한다.

1. 화면 하나를 정한다.
2. 현재 문제를 문서에 기록한다.
3. 색/간격/타입/컴포넌트 문제를 나눠 수정한다.
4. 관련 공통 컴포넌트가 있으면 먼저 고친다.
5. `dart format`과 `flutter analyze`를 실행한다.
6. 변경 내용을 이 문서에 기록한다.

화면을 조금씩 고치되, 기준 없이 여기저기 바꾸지 않는다. 디자인 시스템 기준을 먼저 만들고 각 화면에 확산한다.

## 7. 금지할 방향

- 넓은 파란색/회색 배경을 화면 전체에 까는 방식
- 카드 안에 카드가 계속 중첩되는 방식
- 두꺼운 구분선으로 영역을 나누는 방식
- 너무 많은 색상으로 상태를 표현하는 방식
- Flutter 기본 `Card`, `Chip`, `Dialog` 느낌을 그대로 노출하는 방식
- 차트보다 범례/여백/박스가 더 눈에 띄는 구성
- 디자인 개선 없이 단순히 폰트만 키우는 방식
